## 1. Contexto del proyecto

Studio Milano es un emprendimiento dedicado al rubro de la belleza y la estética de uñas, especialmente al diseño y aplicación de uñas acrílicas.

El sitio web tiene como objetivo dar a conocer el emprendimiento, mostrar sus diseños y servicios, compartir información sobre el cuidado de las uñas y facilitar la comunicación con los clientes.

La página está dirigida a personas interesadas en la belleza, el cuidado personal y los diferentes estilos de uñas. A través del sitio, los visitantes pueden conocer el emprendimiento, revisar las publicaciones del blog y comunicarse mediante el formulario de contacto.

El objetivo principal es entregar una imagen profesional, generar confianza y ofrecer una experiencia de navegación sencilla y agradable.

El sitio utiliza un tema de WordPress que permite organizar los contenidos y personalizar la apariencia de Studio Milano.

La identidad visual busca transmitir elegancia, belleza y profesionalismo mediante la utilización de colores, tipografías, imágenes y una distribución ordenada de los elementos.

**Información del tema:**

- Nombre del tema activo: pendiente de confirmar.
- Tipo de tema: pendiente de confirmar.
- Personalización: colores, tipografías, imágenes y distribución visual relacionadas con la identidad de Studio Milano.

Para instalar nuevamente el tema:

1. Ingresar al administrador de WordPress.
2. Ir a Apariencia > Temas.
3. Seleccionar Añadir nuevo o Subir tema.
4. Seleccionar el archivo ZIP del tema.
5. Presionar Instalar.
6. Activar el tema.
7. Revisar que el sitio se visualice correctamente en computador y celular.

## 7. Cómo realizar un respaldo del sitio web

Para evitar perder información del sitio web, es importante realizar copias de seguridad periódicas.

Se utiliza el plugin All-in-One WP Migration and Backup para facilitar este proceso.

### Pasos para realizar el respaldo

1. Ingresar al administrador de WordPress mediante `/wp-admin`.
2. Ir a Plugins y comprobar que All-in-One WP Migration esté activado.
3. Buscar la opción All-in-One WP Migration en el menú lateral.
4. Seleccionar Exportar.
5. Elegir la opción Archivo.
6. Esperar a que se genere el respaldo completo.
7. Descargar el archivo generado al computador.
8. Guardarlo en una carpeta segura.

El respaldo permite conservar información importante del sitio, como páginas, entradas, imágenes, temas, plugins y configuraciones incluidas en la exportación.

También es recomendable guardar una copia de la base de datos desde phpMyAdmin y conservar los archivos del sitio mediante FTP o el administrador de archivos del hosting.

## 8. Cómo reinstalar el sitio web en otro servidor

Si en el futuro se necesita trasladar Studio Milano a otro hosting, se deben seguir los siguientes pasos:

### Paso 1. Preparar el nuevo servidor

- Contratar un hosting compatible con WordPress.
- Crear una base de datos.
- Instalar WordPress.
- Ingresar al panel de administración.

### Paso 2. Instalar el plugin de respaldo

1. Ingresar a Plugins > Añadir nuevo.
2. Buscar All-in-One WP Migration and Backup.
3. Instalar el plugin.
4. Activarlo.

### Paso 3. Importar el respaldo

1. Ingresar a All-in-One WP Migration.
2. Seleccionar Importar.
3. Elegir Archivo.
4. Seleccionar el respaldo descargado anteriormente.
5. Esperar a que termine la importación.
6. Confirmar la restauración cuando WordPress lo solicite.

### Paso 4. Revisar el sitio

Después de la importación se debe comprobar:

- Que la página de inicio funcione correctamente.
- Que las páginas y publicaciones estén disponibles.
- Que las imágenes se visualicen correctamente.
- Que el tema esté instalado y activo.
- Que los plugins funcionen correctamente.
- Que el formulario de contacto permita enviar mensajes.
- Que los enlaces y menús funcionen correctamente.

Finalmente, se deben revisar los enlaces permanentes desde Ajustes > Enlaces permanentes y guardar los cambios.

**Importante:** la importación puede reemplazar el contenido existente del WordPress de destino. Se recomienda realizar un respaldo antes de comenzar.
